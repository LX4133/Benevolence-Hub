## 首版技术方向

首版明确做基于飞书生态的应用，以多维表格为业务数据底座，优先复用附件、权限与应用能力；具体形态待验证。不默认新建独立业务数据库或账号后台。基于飞书不代表已确定强制注册飞书；需验证目标用户的身份关联、账号门槛和文件访问。

Demo优先使用飞书测试表中的模拟数据，验证读取、更新及附件链路。权限暂未具备时可先本地模拟，但须说明接入未验证。原登录附图仅作备选，不作为当前实施依据。

## 本期范围

三个主导航：**首页／捐赠与发票／我的**。首页保持简版；“我的”展示问候、累计统计、证书与材料入口及捐赠经历，全部历史在“捐赠与发票”查询（按用户要求，原“最近3次捐赠”摘要已移除）。P0覆盖身份与资料隔离、记录查询、票据和证书获取、缺项帮助及复用现表维护；协议、项目报告和细分办理进度为P1，条件具备时纳入。

不做新捐赠报名、活动报名、志愿者管理、积分等级和完整全旅程门户；不默认新建管理后台、跨企业同步或升级投后管理表。
