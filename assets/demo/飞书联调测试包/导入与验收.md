# 飞书联调测试包

在测试企业新建多维表格，将两个 CSV 分别导入为「捐赠记录」「证书与材料」。检查日期和金额字段类型。保留记录编号、演示捐赠人编号为文本，状态可设为单选。

CSV 的文件名列用于定位文件。分别在两个子表新建「票据附件」「材料附件」附件字段，按文件名从「示例附件」目录手动上传到对应行。文件名为空的行保持无附件。D-001 的状态和附件故意不一致。

接通测试表后验证：

| 操作 | 预期 |
| --- | --- |
| 将 D-004 项目名称改成「社区阅读计划（更新测试）」并刷新 | 列表与详情都显示新名称 |
| 用 DEMO-001 筛选 2025 或 2026 | 每年各有两笔记录。「我的」只显示最近三笔 |
| 打开 D-004、D-002、D-005 | 各自身份可打开匹配的示例票据 |
| 打开 D-003 或 D-006 | 显示暂未提供，仍保留捐赠记录 |
| 打开 D-001 | 无附件时不能显示可打开入口 |
| 查看 DEMO-001 的证书和项目报告 | 证书只显示一次。报告仅在获授权且纳入 P1 演示时展示 |
| 切换 DEMO-002 | 不显示 DEMO-001 的记录或附件 |
| 测试无记录与身份未关联 | 已关联且无捐赠可用 DEMO-003 测试。未关联身份另测 |

全部资料均为虚构。当前 Demo 仍使用本地数据，完成测试表接入后再执行上述验收。
